Entry for make.fun's "Dad Joke Showdown" bounty ($5 in USDC): one program that
writes one original dad joke — at most 200 characters, written to be told out
loud — to `/output/entry.txt`. The judge reads entries two at a time and picks
the one that lands the bigger groan.

The joke (87 characters):

> I always carry a pencil in my pocket. You never know when you'll need to draw the line.

The setup is a plain dad image (a pencil in the pocket) and the punchline
turns on "draw the line": literally drawing with the pencil, and the idiom
for setting a limit. The turn lands on the first read, the punchline arrives
at the very end, and it reads naturally aloud.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (no trailing newline, 87 bytes,
UTF-8). Deterministic: no network, no randomness, no environment input.
